# 遼東 Liaodong · 明清戰爭

A deterministic-lockstep three.js game about the Ming–Qing war (1619–1644): first-person battles in tight formation, story
campaigns (浙兵 The Zhejiang Company, 後金 the Jin campaign, 神機營 The Divine Engine Division), co-op missions, sieges,
duels and online play over WebRTC.

Play: https://laladehulu.github.io/Liaodong/

Build: `bash build.sh` (writes `dist/`), then open `dist/test.html`. Test: `node test/test_lockstep.js` must print
"3 peers IN SYNC".

Read [HANDOFF.md](HANDOFF.md) before changing anything: editions, source map, hard rules, how to send changes.
